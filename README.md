A modern web application built with Next.js 16 and TypeScript.

## Features

- Modern web application
- Admin dashboard
- Database integration
- Authentication system

## Quick Start

```bash
npm install
npm run dev
```

Open browser: `http://localhost:3000`

## Tech Stack

- Next.js 16
- TypeScript
- PostgreSQL
- Prisma ORM
